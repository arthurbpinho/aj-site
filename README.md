# Academia Junguiana — site institucional

Site institucional da **Academia Junguiana**, escola de formação em psicologia
analítica junguiana e parte do ecossistema **[Allos](https://allos.org.br)**.

---

## O que dá pra fazer no site

- **Conhecer e comprar os cursos** — catálogo com filtro, página de detalhe por
  curso e checkout via Hotmart (plano mensal ou anual).
- **Seguir uma trilha de estudos** — conteúdo organizado por progressão, do
  introdutório ao avançado.
- **Ler o blog** — artigos sobre teoria e prática junguiana.
- **Explorar as Ampliações** — aprofundamento em conceitos específicos da obra
  de Jung.
- **Conhecer o corpo docente** — coordenadores e professores responsáveis por
  cada curso.
- Uma página estilo **link-in-bio** central para tráfego vindo do Instagram/YouTube.

---

## Stack técnica

**Frontend** — React + Vite, Tailwind CSS (paleta cream/parchment, verde
floresta e dourado), Framer Motion para transições e reveal on scroll, React
Router em modo SPA.

**Infra** — deploy automático (GitHub Actions) no GitHub Pages a cada push na
`main`, com suporte a domínio próprio.
